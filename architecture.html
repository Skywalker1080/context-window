Context Window — High-Level Architecture

How the pieces connect · where each API lives · what protects it

* /api/semantic-search shown as “search”. Solid violet = HTTP calls · dashed grey = Supabase client SDK / realtime socket.

HopDeployed onAuth

/api/embed|search|backfill → ai serviceRailway · Python/FastAPIuser Bearer token in · X-API-KEY out
ai service → postgresSupabase service-role key (bypasses RLS, enforces user_id per query) → link_embeddings

Read the diagram top-down: the user lives in the browser (PWA + IndexedDB offline mirror). Vercel serves the UI and four thin proxy routes — no business logic lives there. Data reads/writes go straight from the browser to Supabase; scraping and embeddings fan out to AWS and Railway and rejoin via Postgres + realtime. Known gap: the ALB is HTTP-only, so the scraper API key travels in plaintext — add an ACM cert + HTTPS listener before treating this as hardened.
