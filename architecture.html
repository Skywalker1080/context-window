Flow 1 — Add a link

sequenceDiagram
  autonumber
  actor U as User
  participant C as LinksContext (browser)
  participant V as /api/scrape (Vercel)
  participant F as Fargate Scraper (AWS)
  participant S as Supabase Postgres
  participant R as Supabase Realtime
  participant I as IndexedDB
  participant E as Semantic-search svc

  U->>C: paste URL · addLink()
  C->>C: assertOnline() · optimistic insert
  C->>I: upsertLocal()
  C->>V: GET /api/scrape?url=…
  V->>F: POST /scrape · X-API-KEY
  F-->>V: {title, description, favicon, thumbnail}
  V-->>C: metadata
  C->>S: insert into links (RLS checks auth.uid())
  S-->>C: .select("*").single() → server row
  S->>R: WAL → publication
  R-->>C: broadcast (all tabs)
  C->>I: write-through mirror
  C-)E: POST /api/embed {linkId} (fire-and-forget)
  E->>S: write link_embeddings (service_role)

Flow 2 — Semantic search

sequenceDiagram
  autonumber
  actor U as User
  participant C as Browser
  participant V as /api/semantic-search (Vercel)
  participant E as Semantic-search svc
  participant S as Supabase Postgres

  U->>C: type query
  C->>V: POST {query} · Bearer JWT
  V->>V: verify JWT → user_id
  V->>E: POST /search · X-API-KEY · {query, user_id}
  E->>E: embed query text
  E->>S: RPC match_links(embedding, user_id, threshold, count)
  S-->>E: ranked link_ids (HNSW cosine)
  E-->>V: results
  V-->>C: results
  C->>S: fetch full link rows (RLS-scoped)
  S-->>C: link objects
Schema source of truth: supabase/migrations/ · Secrets: Vercel env · SSM /context-window-scraper/api-secret · service_role key lives only on the semantic-search service
